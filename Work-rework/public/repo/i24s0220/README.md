Work
===============
git clone - для создания удаленного репозитория (скопирует)
git add . - добавляет все текущие изменения в каталоге или файле
git commit -m "111" - фиксирует изменение и создает новый коммит указаным в "_"
git push - отправляет локальные коммиты в репозитории/ отправить в репозиторий
git pull - забрать
git status - показывает текущее состояние в репозитории
