Work
===============
git clone - для создание удаленного репозитория/скопирует
git add . - добавляет все текущии изменение в каталоге или файле
git commit -m "111" - фиксирует изменение и создает новое коммит указеным в "_"
git push - отправляет в удаленный в репозиторий/ отправить в репозиторий
git pull - забрать из репозитория
git status - показывает текущие состояние в репозитории
