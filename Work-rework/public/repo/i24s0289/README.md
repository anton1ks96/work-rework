git clone - для создания локальной копии репозитория(+ ссылка)

git add . - добавляет все изменения в каталогах 

git commit -m "111" - фиксирует изменения доюавленных в индекс

git push - отправляет локальные коммиты в удаленные репозитории

git pull - как предыдущая команда, только забирает

git status - показывает текущее состояние репозитория
