# Git

## Базовые комманды

```
git init - инициализировать локал.репозиторий
git remote add "имя реп-рия""ссылка на реп-рий github" - подключить лок.реп-рий
git remote rm "имя" - отключение от удаленного реп-рия
git add "имя файла" - добавить файл для коммита 
git commit -m "коммент к комиту" - сохранить изменения в добавленых файлах 
git push "имя реп-рия" - добавить все изменения 
git clone "ссылка на реп-орий" - клонируешь удаленный реп-орий
git pull - запулить файл с удаленного реп-рия 
```
