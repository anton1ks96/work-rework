# WorkRework Project

## Описание проекта

**WorkRework** - это проект по переработке учебного пространства для работы с репозиториями. Мы стремимся создать максимально удобную и интуитивно понятную среду.

## Прогресс

### Фронтенд
- **Срок разработки:** до 28 февраля 2025 года.
- **Статус проекта:** Pre-Alpha (v0.85)

## Как запустить проект?

1. 📂 **Открыть репозиторий** проекта.
2. 🔍 **Открыть командную строку** в корневой директории проекта.
3. 💻 Ввести команду `npm install` чтобы установить нужные пакеты для работы.
4. 💻 Ввести команду `npm run dev` для запуска локального сервера.
